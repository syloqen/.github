# Contributing to Syloqen

Thanks for taking the time to contribute.

## Before you begin

Please search existing issues and pull requests before opening a new one. For a
substantial feature, design change, or new module, open an issue first so the
approach can be discussed before implementation begins.

## Issues

Use the available issue forms and include enough context for someone else to
understand and reproduce the problem. Do not include credentials, Terraform
state files, private endpoint details, or other sensitive information.

## Pull requests

Keep pull requests focused and explain both the change and its motivation.

- Link the relevant issue when one exists.
- Update documentation, examples, and changelog material when they are affected.
- Run the validation and tests documented by the target repository.
- Call out breaking changes, new permissions, or changes to defaults clearly.

By contributing, you agree that your contributions may be distributed under the
license of the repository you contribute to.
